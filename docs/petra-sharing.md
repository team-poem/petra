# 작업 중 상대가 어떻게 아는가

상대 에이전트는 내 화면이나 로컬 디스크를 직접 볼 수 없다. PETRA가 Git 원격에 전송하고 상대가 조회한 정보를 읽는다.

| 전달할 것 | 언제 보내나 | 무엇이 보이나 |
|---|---|---|
| 작업 목표 | 시작 claim을 커밋·push | 누가 어떤 브랜치에서 무엇을 만드는지 |
| 아직 커밋하지 않은 코드 | `share` 또는 `pulse`, Claude 편집 훅, `run`의 주기 전송 | 편집 파일과 별도 Git 스냅샷 |
| 완료한 작은 변경 | 에이전트가 검증 후 `checkpoint`, 또는 일반 commit·push | 동료 브랜치에서 사용할 수 있는 코드 |
| API/타입 변경, 질문, 작업 완료 | 그 시점에 새 저널을 커밋·push | 동료가 해야 할 행동과 바뀐 계약 |

스냅샷은 `refs/wip/<handle>/<branch-slug>`에 별도 커밋 객체로 저장된다. **브랜치 HEAD와 실제 인덱스는 바꾸지 않는다.**
파일명만 전송하는 것은 아니다. 미추적 파일을 포함해 `.gitignore`가 제외하지 않은 **내용도 전송**하므로 비밀정보를 먼저 제외한다.
저널은 일반 브랜치에서 읽는다. 스냅샷에만 있는 저널 초안은 동료의 이벤트 목록에 전달되지 않는다.

## 에이전트가 중간에 하는 일

새 세션은 `digest --fetch --session`으로 시작한다. 같은 세션의 재조회에는 `--session`을 빼 중복 알림을 줄인다.
파일 몇 개를 고친 뒤 `pulse`로 주고받는다. 독립된 변경이 검증됐으면 다음처럼 선택한 파일만 커밋한다.

```sh
sh .petra/bin/petra checkpoint --message "가격 함수의 통화 인자를 추가한다" -- lib/price.js
```

기존 staged 변경이 있으면 섞지 않고 중단한다. 커밋 뒤 push가 실패하면 로컬 커밋을 남기고 알려준다.
타이머가 임의 시점에 코드를 커밋하지 않는다. **에이전트가 의미 단위와 검증 결과를 판단해서 호출**한다.
함수 계약이 바뀌었다면 새 저널 이벤트도 이때 공유한다. 세션 종료까지 기다리지 않는다.

## 자동으로 되는 범위

- Claude: 편집 훅이 기본 15회 호출 또는 마지막 pulse 후 15분 경과를 **다음 도구 호출에서** 확인한다. 대기 중 매 15분 실행하는 데몬이 아니다.
- Codex: 공통 계약과 `petra` 스킬에 따라 위 CLI를 직접 호출한다. 설치기가 전역 권한이나 미검증 자동 훅을 추가하지 않는다.
- 둘 다: Git post-commit이 스냅샷과 upstream이 있는 브랜치 push를 시도한다. 실패 시 커밋은 성공 상태로 남기고 경고한다.
- 긴 워커: `run -- <명령>`이 실행 중 기본 60초마다 `share`만 실행한다. HEAD를 바꾸는 자동 merge와 별도 checkpoint는 보류한다. 워커가 끝나면 주기 전송도 끝난다.

`share`는 전송/조회만 한다. `pulse`는 추가로 새 알림과 안전한 main 따라잡기를 수행한다.
Sobaya가 완료 항목을 커밋하는 일은 Sobaya의 책임이며 PETRA가 대신 커밋하지 않는다.

## 전송 상태 읽기

`digest --json`의 `sharing.publish`, `sharing.fetch`, `sharing.branch`는 각각 스냅샷, 원격 조회, 자동 브랜치 push다.
`succeeded_at`은 마지막 성공 시각이며 실패했을 때 갱신하지 않는다.

- `ok`: 최근 해당 동작 성공. 전송 뒤 상대가 실제로 읽었다는 확인 응답은 아니다.
- `failed`: 시도 실패. 이전 정보만 남아 있을 수 있다.
- `stale`: 마지막 성공이 오래됐다.
- `unknown`: 아직 확인한 적이 없다. 수동 push를 자동 push 성공 기록으로 오인하지 않는다.

동료 claim은 있지만 새 스냅샷이 없으면 **현재 편집 상태 미확인**이다. 작업 종료나 충돌 없음으로 해석하지 않는다.
원격 접근이나 `.git` 캐시 쓰기가 도구 권한에 막히면 필요한 범위의 권한을 확인한다. 샌드박스를 전역으로 해제하지 않는다.

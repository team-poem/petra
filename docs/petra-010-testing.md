## 실제 에이전트 smoke

내부 실험실의 두 clone에서 생성한 협업 기록을 읽는 제한된 테스트다. 전체 앱 개발·승인·병합을 두 모델이 완료했다는 뜻은 아니다.

- **Codex 첫 실행**: 공통 계약과 petra 스킬을 읽고 현황을 요청했다. sandbox가 테스트 `.git/petra` 쓰기를 막자 최신 조회 실패와 캐시를 구분해 보고했다.
- **Codex 두 번째 실행**: 같은 fixture의 Git 메타데이터만 추가 쓰기 경로로 허용했다. `digest --fetch --session`의 원격 조회가 성공했고 amazon의 장바구니 목표, KRW 답변, 미머지 변경을 읽었다. 구형 브랜치를 수동 재조회할 때 새 경로를 먼저 찾는 한계도 보였으므로 프로토콜 테스트와 모델 이해를 동일시하지 않는다. 코드/문서/설정 수정, commit/push는 하지 않았다.
- **Claude Code 2.1.258**: SessionStart가 PETRA 계약, 전송 상태, 동료 목표·이벤트를 주입했고 petra 스킬을 발견했다. 모델 호출은 조직 구독 접근 제한 `oauth_org_not_allowed`(403)으로 중단됐다. **Claude의 이해·응답 행동은 미검증**이다. 계정·조직 설정을 변경하지 않았고 모델 비용은 0이었다.

재현용 `tests/petra-agent-smoke.mjs`는 명시적으로 실행할 때만 모델 CLI를 호출한다. 내부 실험실 경로만 허용하고 150초, Claude 최대 1달러로 제한한다. CI에서는 모델을 호출하지 않는다.
로그는 로컬 evidence 디렉터리에 둔다. 실제 토큰·인증 자료나 모델 세션 전체를 배포물에 넣지 않는다.

## 남아 있는 경계

원격 관측은 실시간 상호 배타 잠금이 아니다. 일반 commit 시점 결정은 에이전트 계약이고 타이머의 강제 코드 커밋이 아니다.
구형 외부 Sobaya 소스 클론 연결과 사용자 수정된 알 수 없는 하네스는 자동 변환하지 않는다.
팀 승인, 앱 고유 테스트, GitHub 서버의 보호 규칙은 설치 성공과 별도로 확인한다.

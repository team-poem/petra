# PETRA 0.1.0

여러 개발자의 에이전트가 같은 프로젝트에서 동시에 일할 때 필요한 작업 공유와 프로젝트 설치 수명주기를 묶었습니다.

## 작업 중 협업

- 미커밋 파일은 Git 스냅샷으로 공유합니다. 전송/조회/브랜치 push 상태와 마지막 성공 시각을 구분하고 실패를 숨기지 않습니다.
- `run -- <명령>` 실행 중에도 기본 60초마다 공유합니다. 워커의 HEAD·실제 인덱스·Sobaya 승인 상태에 커밋이나 merge를 끼워 넣지 않습니다.
- 에이전트가 검증한 의미 단위에 `checkpoint`로 선택한 파일만 커밋·push합니다. 계약 변경은 중간 저널로 알리고, 새 세션에서는 관련 이벤트를 다시 읽습니다.

## 설치와 유지보수

- `install`, `update`, `rollback`, `migrate`는 변경 계획을 먼저 확인합니다. 앱 코드·README·Test 명령, 사용자 설정, 팀 기록과 설치형 Sobaya 연결을 보존합니다.
- 구형 기록은 바이트가 같은 이동만 허용합니다. 출처와 다른 사용자 파일은 자동 삭제하지 않습니다. 구형 소스 클론 Sobaya 연결은 별도 검토가 필요합니다.
- 일반 실패는 이번 변경만 복구합니다. 강제 종료 뒤에는 `recover`로 백업을 검사하고 동시 편집이 없는 파일만 복구합니다.
- 소비 프로젝트에 짧은 `petra` 스킬, 첫 합류 안내, 별도 PR 양식과 읽기 전용 협업 CI를 제공합니다.

## 도구와 검증

공통 AGENTS와 CLI가 기준입니다. Claude는 에디터 훅을 사용하며 Codex는 명시적인 협업 명령을 호출합니다. Git 훅은 도구와 관계없이 실행됩니다.
Linux/macOS 회귀, 실제 두 clone, 실패·복구, 공개 Sobaya 런타임 검증은 CI에서 확인합니다. 실제 모델 smoke의 결과와 제약은 `docs/petra-010-testing.md`에 구분해 기록합니다.

## 설치 자산

`petra-0.1.0-source.tar.gz`는 설치·업데이트 도구와 문서를 포함한 소스입니다. `petra-0.1.0.tar.gz`는 검사용 소비 패키지이며 기존 프로젝트에 직접 덮어 풀지 않습니다.
`manifest.json`과 `SHA256SUMS`로 출처 커밋과 파일 해시를 확인합니다. 최초 설치는 소스의 `docs/petra-install.md`, 이전/업데이트는 `docs/petra-lifecycle.md`를 참고하세요.

스냅샷에는 ignore하지 않은 파일 내용도 전송됩니다. 비밀정보는 먼저 제외해야 합니다. 원격의 마지막 관측을 공유하는 도구이지 실시간 잠금이나 무충돌 보장은 아닙니다.
